Lists & rules

Blocked sites & patterns

A plain domain blocks it and all its subdomains — no * needed. Use * only for patterns a domain can't express (ads*.example.com, *tracker*).

Rules file (/rules.cfg)

One rule per line: block <d>, wildcard *.x.y, allow <d>, keyword <t>, url <substr> (AdGuard ||d / @@||d also work). url blocks a URL the client's PAC sees (path included) — needs the PAC set on the device; see Proxy below. Editing here replaces the whole file.

Proxy (PAC)

Point your browser/OS automatic proxy (PAC) setting to http:///proxy.pac (or the WPAD alias /wpad.dat). url rules (above) then route matching URLs here to be dropped — no proxy/cert needed. The Proxy address below is a separate, real proxy for everything else; leave empty for direct.

Servers to forward to
