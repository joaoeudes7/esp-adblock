3 Prefer configs baked into the image?

The firmware reads /wifi.cfg (baked from config.env) and secrets.h before falling back to runtime provisioning. To ship a pre-configured image instead of using step 2, fill config.env, rebuild, then re-run tools/build_installer.py:

cp config.env.example config.env  # edit it
pio run -e esp8266 && pio run -t buildfs -e esp8266
python3 tools/build_installer.py

Use this only for a trusted build you control — the credentials end up inside the public .bin.
